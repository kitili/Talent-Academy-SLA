# Trainer walkthrough

You train adult teachers. The pictures of children are the pupils those teachers will teach. You only see the cohorts an admin assigned to you. You can add courses. An admin adds cohorts and the batches inside them.

Primary trainers cover playgroup through Standard 7. Secondary trainers cover Form I.

## A. Sign in

Open the Trainer tab and sign in. The first visit starts a short tour. **Tour** in the header plays it again.

## B. Your desk

You land on Your cohorts.

The strip at the top is the whole ladder: Playgroup, Pre-primary, Standard 1–2, Standard 3–6, Standard 7, and Secondary. Your own stage is highlighted. Another trainer’s batch is not in the list on the left.

## C. Open a batch

Pick the batch. The name is the class those teachers are learning to teach, for example **Playgroup — Montessori** or **Secondary — Form I**.

Six tabs sit on the batch:

| Tab | What you do |
| --- | --- |
| Teachers | See who is enrolled. Add a teacher. Write feedback. Send a short desk note. |
| Quizzes | Assign a module quiz, including a question you write yourself. |
| Progress | See the same course percent the teacher sees. |
| Attendance | Mark who came. |
| Schedule | Put a session or a deadline on the calendar. |
| Certificates | Issue a certificate when a course is complete. |

**Open cohort room** is the class office: roster import, written work, marking, the calendar, and a note to the whole batch.

## D. Build the course

**Courses** in the header is the curriculum. Add a course there. An admin places that course on a batch inside a cohort.

A course is one stage. A module inside it is one focus, such as Practical life or Kiswahili. A lesson file sits inside the module. The course page reminds you to plan each module as Introduction, Competence development, Design, then Realisation. Playgroup uses the five Montessori areas instead of that subject list.

Draft courses stay hidden from teachers. Published courses appear on their desk after the course is assigned to their batch.

## E. Let someone in

**Approvals** accepts a new teacher. You can reset that teacher’s password. You cannot create an admin, clear the academy, or open another trainer’s batch. An admin assigns you to a batch.

## F. A normal week

1. Confirm the teachers are in your batch.
2. Confirm the course for that stage is assigned.
3. Add or check the lesson file on the current module.
4. Assign the quiz, or set a written task in the cohort room.
5. Put the live session on the calendar.
6. After they work, read progress, mark written work, and mark attendance.
7. Write a feedback comment when one teacher needs a note that is not a score.
8. Send a batch note when the whole class needs the same message.
