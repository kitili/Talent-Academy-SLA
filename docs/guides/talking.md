# How trainers and Fellows talk

They share one cohort. They do not share one chat room. Each kind of message has a job.

## They reply to each other

| Point | Who starts | Where | What comes back |
| --- | --- | --- | --- |
| Desk mail | Either person | Trainer: **Messages** tab. Fellow: **Messages** tab on the desk, with their trainer. | A short 1:1 thread. The other person also gets a bell notice, "New desk message". |
| Written work | Trainer | Cohort room. The Fellow sees it in **My work**. | The Fellow submits a written answer. The trainer scores it from 0 to 100 and writes a comment. The Fellow sees the mark on **My work** and a bell notice, "Written work marked". |
| Feedback comment | Trainer | The comment button on the Fellow's row, on the cohort's **Progress** tab. Categories: progress, improvement, general. | The Fellow reads it under **Trainer feedback**. There is no reply box. |
| Cohort note | Trainer | Cohort room, **Announce**. | Every Fellow in that cohort gets it under **From the academy** and in the bell. They do not answer inside the note. |

Use desk mail when one Fellow needs a private reply. Use a cohort note when the whole class needs the same sentence. Use written work when you need a piece of work and a mark. Use a feedback comment when you are judging progress and do not need an answer.

## They are connected, but it is not a conversation

| Point | What happens |
| --- | --- |
| Joining a cohort | The Fellow gets a notice: "You're in". |
| Calendar | The trainer adds a session or a deadline. The Fellow sees it on **My calendar** and gets a bell notice. |
| Quiz result | The quiz screen shows the Fellow the result, and the correct answers only after a pass. For a quiz or exam the trainer assigned, a second miss sends a notice, "Quiz needs another try", and three misses end the attempts until the trainer resets them. The trainer sees the same pass or fail on **Progress**. |
| Progress and attendance | The trainer marks attendance and reads the course percent. The Fellow sees the same percent and their own attendance. Nobody types a message. |
| Certificates | An admin issues a certificate after a course is complete. The Fellow opens it from **Certificates**. The trainer sees the issued ones under **Graduates** in the cohort room. |
| Reflection | The Fellow writes it on their desk. Admin analytics can read it. It does not appear on the trainer's cohort page. |
| Course rating | The Fellow scores the course. That score goes to analytics, not into a thread with the trainer. |
| Module discussion | A Fellow posts on the lesson page, and the other Fellows in the cohort can read it. The trainer's screens do not open that thread, so a post there does not reach the trainer's desk. A trainer view of the thread, with replies, is not shipped. |

## Where the admin speaks

The admin does not sit in desk mail. Private replies stay between a trainer and a Fellow.

| Point | What happens |
| --- | --- |
| Academy notice | Admin only, from the header. It goes to every approved trainer and every approved Fellow. They see it in the bell. There is no reply. |
| Any cohort room | An admin can open every cohort. From that room they can send a cohort note, set written work, and mark it, the same way the assigned trainer can. |
| Password reset | Admin sets a new password. That is not a message, and the old password cannot be shown. |

Send an academy notice when the whole academy needs one sentence. Leave a single Fellow's question to that Fellow's trainer.

## When they need to talk

Talk when a lesson file or its quiz is missing, when written work is unclear, when a quiz has been missed twice, when attendance does not match the session, and when one Fellow needs a different explanation from the rest of the cohort.

Do not use talk for a pass mark, a locked module, or a certificate. Those move by themselves once the work is done, except the certificate, which an admin issues.
