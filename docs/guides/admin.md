# Admin walkthrough

You run the academy. Trainers coach the teachers. You decide who those trainers are, which batch they own, and when the whole school needs one message.

Sign in on the Admin tab. The first visit starts a tour. **Tour** in the header plays it again. The tour points at each control in the top bar, then each navbar name, and leaves that control clear so you can read it while the page moves.

## A. The desk

You land on the admin home. A short line shows trainers, teachers, and courses. If someone is waiting, **Needs attention** opens Approvals. The pictures below open the rest of the academy.

## B. The header

| Control | What it does |
| --- | --- |
| Academy mark | Silverleaf Academy, and the line that says this is the admin desk. |
| Signed-in account | The admin username, so you can see which desk is open. |
| Tour | Replay the walk of the bar and the navbar. |
| Academy notice | On the desk, under the pictures. One note to every approved trainer and every approved teacher. It lands in the bell. They do not reply inside it. |
| Reset password | On the desk, next to Academy notice. Set a new password for any account. The old password is stored hashed, so you cannot read it. |
| Bell | Notices sent to you. A red number means unread notes. |
| Light and dark | Switches this browser between a light page and a dark page. |
| Logout | Signs this admin account out. |

## C. The navbar and the cards

The navbar stays on the admin pages: Desk, Approvals, Trainers, Teachers, Cohorts, and Analytics. Courses are added inside a batch, so there is no Courses tab.

| Card | What you do |
| --- | --- |
| Approvals | People ask for a desk from the sign-in page. Sign them in here, or turn them away. They create their own password after you approve. **Export history** downloads every saved approval as a CSV file. |
| Trainers | Create a trainer account. A trainer you create here is approved at once. Open a trainer to see that account. |
| Teachers | Create a teacher account, already approved. Open a teacher to see progress and files viewed. |
| Cohorts | One place for three different things. A **cohort** is the group, and it can have more than one trainer. A **batch** is a step inside that cohort, and each batch can hold more than one teacher. A **course** is the lessons on a batch. Set how many cohorts a teacher finishes. You add cohorts, batches, and courses here. Open or close the cohort and its quizzes. A trainer can add courses only. |
| Analytics | The gradebook for the whole academy: teachers, open cohorts, completion, attendance, quizzes, reflections, course ratings, and who is at risk. |

## D. The job only you do

A trainer sees only their own cohorts. You see all of them, and you are the person who puts a trainer on a cohort. Until you do that, the trainer’s desk stays empty.

You add cohorts and the batches inside them. A trainer cannot. A trainer can add a course, and so can you. You can also create trainer accounts. A trainer cannot create another trainer or an admin.

## E. Start fresh

**Clear previous activity** removes only the areas you tick: cohorts, progress, quizzes, certificates, or notices. Tick the trainers or teachers it applies to. It does not clear the whole academy, and it does not remove courses or login accounts. Type `CLEAR ACTIVITY` only when you mean it. You stay signed in.

On Cohorts, each cohort has an **Approval history** dropdown. It stays closed until you select it, then it pages the rows already saved for that room. **Export** downloads them as a CSV file.

## F. A normal week

1. Approve anyone waiting.
2. Confirm each batch has the right trainer. Close a cohort, or stop its quizzes, when that class should pause.
3. Confirm the course for that stage is published and assigned.
4. Send an academy notice only when every desk needs the same sentence.
5. Open Analytics when you need the school picture, not one class.
6. Open a cohort room when you need to do the trainer’s work yourself.
