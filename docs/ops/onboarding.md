# Onboarding

Fellow (teacher) sign-up, batches, and course assignment.

- `teachers` — fellow accounts (`teacher_id` numeric starting 7100).
- `teacher_profiles` — extra fellow details.
- `batches` — cohorts. An admin creates them and assigns a trainer.
- `academy_settings` — how many cohorts a teacher finishes before they are done.
- `cohort_batches` — the batches inside one cohort. Each cohort can have a different number.
- `batch_teachers` — who is in which cohort.
- `batch_courses` — which courses a cohort studies.
