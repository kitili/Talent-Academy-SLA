# Trainer guide

Sign in on the Trainer tab.

1. Open **Batches** to see your cohorts and each teacher's course percent. Finished courses are not labelled At Risk.
2. Assign **Classroom Practice** (or any published course) to a cohort. Draft courses stay hidden from teachers.
3. Add a calendar session or a written assignment from the cohort page.
4. Export the roster as CSV from the cohort tools.
5. Review quiz attempts. The pass mark, question order for learners, and completion percent match what the teacher sees.

You can approve new teacher accounts. You cannot change another trainer's password or create admins.
