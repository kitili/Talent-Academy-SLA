The three certificates, on the real templates

An Admin issues every certificate by hand. The app draws the Fellow's name and the wording over the official template; the name printed in each template image is covered.

How a certificate is issued

  1. The server works out who is ready; the Admin sees them first on Certificates.
  2. The Admin picks the Fellow and the kind, and sees this preview with the name filled in.
  3. The server checks the rule again and refuses with a plain reason if the Fellow is not ready.
  4. The Fellow finds it on their Certificates page, to view or download as a PDF.
