Proposed · the shell every desk shares

One header, one menu, one accent colour

Admin, Trainer and Fellow get the same frame and change only their menu items. The cohort room opens inside it too, so nobody loses the menu. Colour is kept for meaning, and photos never sit behind text.

  1. 1Header, the same on every desk. Logo, desk name, Help, Notifications, Dark mode, the person's name and Log out. Every icon button has a name a screen reader can say.
  2. 2One side menu. It replaces the admin photo cards, the trainer's coloured pills and the cohort room's missing menu. A count sits beside an item only when work waits there.
  3. 3Page header. The title, the date where it helps, and one primary action.
  4. 4Work first. Each home opens on what needs doing; figures sit below in plain tiles, with a skeleton while they load, never a false 0.
  5. 5Colour means something. Silverleaf blue marks links, the current page and primary buttons. Red, amber and green mean at risk, overdue and passed, and nothing else.
