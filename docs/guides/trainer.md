# Trainer guide

Sign in on the Trainer tab. The first visit opens a short tour. **Tour** in the header replays it.

1. Open **Batches** to see the cohorts assigned to you and each teacher's course percent. Another trainer's cohort is not on this list. Finished courses are not labelled At Risk.
2. Assign **Classroom Practice** (or any published course) to a cohort. Draft courses stay hidden from teachers.
3. Add a calendar session or a written assignment from the cohort page.
4. Export the roster as CSV from the cohort tools.
5. Review quiz attempts. The pass mark, question order for learners, and completion percent match what the teacher sees.

**Courses** in the header is where modules and lesson documents live. **Approvals** lets a new teacher in.

You can approve new teacher accounts and reset a teacher's password. You cannot change another trainer's password, create admins, or clear the academy. An admin assigns you to a class from Cohorts.
