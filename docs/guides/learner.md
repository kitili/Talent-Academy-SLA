# Teacher (learner) guide

Sign in with your email and password on the Teacher tab.

1. **My learning** lists each course, the percent finished, and a status: Not Started, In Progress, Completed, Passed, Failed, or Locked.
2. Open the next unlocked module. Read the lesson, then press **I have read this lesson**.
3. Take the module quiz. You need 80% to pass. The next module stays locked until this one is passed.
4. Certificates appear after the course completion rules are met.
5. Calendar shows sessions. My work is for written tasks besides quizzes.

You only see your own progress. A trainer sees the same percentages.
